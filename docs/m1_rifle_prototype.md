# M1 战斗原型：步枪兵

用原版弩兵的动画和数据做出一个"步枪兵"，验证枪械战斗在三国引擎里的观感、手感和音效。这个原型的结论决定项目去留，对应设计文档路线图里的第一道关卡。

> 下面的表名和字段名参照同代全战（战锤 2）的数据结构写成，三国的实际名称以 RPFM 里显示的为准。最稳妥的做法是：顺着一个原版弩兵的 key 查引用，照它的数据链逐表复制。

## 验收标准

- 观感：射击动作看起来像开枪，弹道平直、几乎瞬间命中。
- 手感：射程、命中率、杀伤和射击节奏像步枪，而不是换了皮的弩。
- 音效：弄清开火声音能不能换；换不了，也要有能接受的替代方案。
- 稳定：游戏正常加载，没有报错或崩溃。

## 开始前

1. 从 [RPFM 的发布页](https://github.com/Frodo45127/rpfm/releases) 下载最新版并解压。
2. 第一次启动时，在设置里填好《全面战争：三国》的安装路径，游戏选 Three Kingdoms，再按提示更新 schema、生成依赖缓存（dependencies cache）。做完这一步才能浏览原版数据表和查引用。
3. 确认游戏能正常进入自定义战斗。后面的测试都在自定义战斗里做，比进战役快得多。

## 第 1 步：新建 pack

1. 在 RPFM 里新建一个 PackFile，把类型改成 Mod。
2. 保存为 `D:\ttw3_models\build\kz_m1_rifle.pack`。`build/` 不进 git。

## 第 2 步：找一个原版弩兵当模板

1. 在原版的 `land_units` 表里搜 `crossbow`，挑一个普通弩兵，记下它的 key。
2. 对这个 key 查引用，列出所有用到它的表。通常有 `main_units`、单位外观、自定义战斗权限和本地化文本。
3. 顺着它的远程武器找到 `missile_weapons` 里的条目，再顺着武器找到 `projectiles` 里的箭矢条目。

## 第 3 步：复制数据链，换成新 key

把模板涉及的每一行复制进自己的 pack，key 统一加 `kz_` 前缀，行与行之间的引用也改成新 key。

| 表（参考名） | 新 key | 作用 |
| --- | --- | --- |
| `projectiles` | `kz_proj_rifle_bullet` | 子弹：射程、初速、伤害、弹道 |
| `missile_weapons` | `kz_weapon_rifle_zhongzheng` | 步枪，指向上面的子弹 |
| `land_units` | `kz_unit_rifle_infantry` | 单位战斗属性，远程武器指向上面的步枪 |
| `main_units` | `kz_unit_rifle_infantry` | 主条目：费用、维持费，指向 `land_units` 的新行 |
| 单位外观相关表 | 新单位 key | 先照抄弩兵的外观 |
| 自定义战斗权限表 | 新单位 key | 让单位出现在自定义战斗的单位列表里 |
| 本地化文本（.loc） | 单位名称、描述 | 例如"步枪兵（中正式）" |

两条要点：

- 表文件起自己的名字，例如 `kz_m1_rifle`，不要和原版同名：同名会把原版整张表替换掉，不同名才是在原版基础上追加行。
- 复制完用 RPFM 的诊断（Diagnostics）检查一遍，确认没有指向不存在的 key。

## 第 4 步：调子弹参数（核心实验）

先只改子弹、弹药和近战武器，其余照抄弩兵。下表只给方向，具体字段以 RPFM 为准：

| 参数 | 调整方向 | 想要的效果 |
| --- | --- | --- |
| 初速 | 大幅提高 | 弹道变平，几乎瞬间命中 |
| 最大仰角 | 调低 | 只能平射，不能隔着友军抛射 |
| 有效射程 | 比弩略远 | 拉开交战距离 |
| 散布、精准度 | 加大散布 | 单发命中率低，靠齐射取胜 |
| 伤害、破甲 | 提高破甲占比 | 子弹能穿透铠甲 |
| 装填时间 | 先和弩持平，测试后再调 | 找到像步枪的射击节奏 |
| 弹丸外观 | 换成最小、最快的弹丸外观 | 看起来像子弹而不是箭 |
| 弹药（在 `land_units`） | 提高 | 能打满一整场仗 |
| 近战武器（在 `land_units`） | 指向原版长矛类武器 | 模拟刺刀冲锋 |

每次只改一两个参数再进游戏测，否则分不清是哪个改动起了作用。

## 第 5 步：进游戏测试

1. 保存 pack，复制到游戏的 `data` 目录（Steam 默认在 `steamapps\common\Total War THREE KINGDOMS\data`）。
2. 在启动器的模组管理里勾选 `kz_m1_rifle`，进入自定义战斗。
3. 至少测下面四组，结果记在第 6 步的表里：
    - 步枪兵对原版弩兵：射程、命中和伤亡对比
    - 步枪兵对原版近战步兵冲锋：接敌前能打出多少伤害
    - 步枪兵对骑兵冲锋
    - 步枪兵站在友军身后：会不会隔着友军开火

## 第 6 步：记录结论（关卡 G1）

- 观感和手感都能接受，音效能换或有替代方案：通过，进入 M3 扩展兵种。
- 观感或手感不能接受：按设计文档的路线图，重新评估是否换用原生支持火器的引擎。

## 存进仓库

测试稳定后，把 pack 里的文件导出到 `packs/kz_m1_rifle/`，数据表导出成 TSV，方便 git 比较差异，然后提交。

## 常见问题

- 单位不在自定义战斗列表里：检查自定义战斗权限表里的阵营和单位 key。
- 改动不生效：确认 pack 类型是 Mod、启动器里已勾选、表文件名没有和原版重名。
- 启动报错或崩溃：用 RPFM 的诊断找缺失的引用，或者先移除最近改的那张表来定位问题。
